# Antigravity 2.13.0 Simplified Chinese — Windows adaptation

Based on MIMICTE/Antigravity-zh-CN at commit 1c40f4d69b4360470f0c14c7e4a6679fd3f75344 (MIT).

See [README.md](README.md) for installation and verification. This adaptation supports the Windows desktop app version 2.13.0 only, not the IDE. It requires Python 3.11+. It does not terminate running processes. Close Antigravity normally before installing or restoring.

Run Install-zh-CN.cmd to install and start the app; Restore-zh-CN.cmd to restore. Original archive hashes are checked. Official updates are never overwritten by old backups. Chat content, code and editable values are excluded from DOM translation. Complete translation coverage is not claimed. macOS/Linux builds are not provided or validated.

Do not distribute the generated build directory: it contains extracted Google application files.
